RainyGlass lens assets
=====================

Upstream: https://github.com/toadstorm/RainyGlassShader
Source package: toadstorm_RainyGlassShader.unitypackage
Upstream license: GNU LGPL 2.1; see ../../../LICENSE-RainyGlassShader-LGPL-2.1
Native port date: 2026-10-05

The two .rgba files in this directory are derived directly from the package's:
  Assets/Textures/droplets_mask.tif  (GUID 76ae1285472e6ce48a2f01ef7905b8fd)
  Assets/Textures/rivulets_mask.tif  (GUID bd357bf0331325748a7c1bd168220b67)

Conversion follows the supplied Unity TextureImporter metadata rather than
retuning/repainting the masks:
  - preserve source R/G/B plus the TIFF fourth sample (Unity alpha)
  - sRGBTexture = 0 (mask channels are linear data)
  - Standalone maxTextureSize = 1024
  - resizeAlgorithm = 0 (Unity's default Mitchell resize)
  - textureCompression = 0
  - repeat wrapping
  - mipBias = -100, so the native sampler is clamped to mip 0

The shader implementation in ../rain_glass.wgsl ports the package's
Assets/Shaders/Effects/RainScrollerShader.shader and uses the exact serialized
RainOnGlass.mat values, with one deliberate deviation:

  - Tiling. RainOnGlass.mat stores (8, 6), authored for a quad of whatever size
    Unity gave it. Applied directly to fullscreen UV that tiles this 1024 mask
    eight times across the width, which at 2560 px is ~3.2 mask texels per screen
    pixel - and the sampler is clamped to mip 0 (mipBias -100), so the
    minification cannot be filtered. That drew every droplet at a third of its
    painted size and aliased the mask into scattered speckles. The port derives
    tiling from the viewport and mask dimensions instead, pinning one mask texel
    to one screen pixel at any resolution and aspect ratio.
